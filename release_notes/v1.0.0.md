## 更新内容

第一个公开版本。

### 新增

- **免安装包**：解压后双击 `ZZZLostVoid.exe` 即可使用，自带 Python 和模型。首次运行有快速设置，默认只显示常用设置，「设置 → 环境」可以打开「显示高级设置」。
- 迷失之地「**计划刷取次数**」（1~99，默认 1）：通关达到次数后自动停止，下次启动重新计数。
- 迷失之地「**难度**」：「获取大部分菲林奖励」可选难度一到难度六，默认难度五。
- 迷失之地「**活性增幅**」：战线肃清可以选「不选 / 指定点数 / 自动选满」。

### 变更

- 刷取目标「获取所有菲林奖励」改名为「获取大部分菲林奖励」，旧配置自动迁移。
- 周期增益固定选第二个。

### 移除

- AI 决策功能（API Key、接口地址、模型等设置，以及预备编队的 1/2/3 号位成员）。

### 开发

- 新增自动化测试（`tests/`）和 GitHub Actions CI。
- 新增打包脚本 `packaging/build.ps1` 和发布工作流。

## What's Changed

First public release.

### Added

- **Portable package**: unzip and double-click `ZZZLostVoid.exe`. Python and models are bundled. The first run shows a quick setup, and only common settings are visible by default; turn on "Show advanced settings" under Settings → Environment to see the rest.
- Lost Void **planned run count** (1–99, default 1): stops automatically after that many clears and starts counting again on the next launch.
- Lost Void **difficulty**: "Get most of the Polychrome rewards" can use difficulty 1 to 6, default 5.
- Lost Void **Activity boost**: for Frontline Clearing you can choose "None / specific points / auto max".

### Changed

- The farming goal "Get all Polychrome rewards" is renamed "Get most of the Polychrome rewards"; old configs are migrated automatically.
- The periodic buff is always the second option.

### Removed

- The AI decision feature (API key, endpoint and model settings, and the member picks for slots 1/2/3 of the prepared team).

### Development

- Added automated tests (`tests/`) and GitHub Actions CI.
- Added the packaging script `packaging/build.ps1` and the release workflow.
