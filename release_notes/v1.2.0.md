## 更新内容

### 新增

- **程序内自动更新**：免安装包启动后会检查 GitHub 上有没有新版本，有就弹窗显示更新说明，点「立即更新」自动下载、覆盖并重启，配置不会丢失。每次更新下载完整包（约 570 MB），下载走「资源管理」里设置的代理。

> 从 v1.2.0 起才有这个功能，旧版本需要手动下载本版本的压缩包。

---

## What's Changed

### Added

- **In-app auto update**: the portable package now checks GitHub for a newer version shortly after launch. If there is one, a dialog shows the release notes; click "Update now" and the app downloads the package, overwrites the install and restarts. Your settings are kept. Each update downloads the full package (about 570 MB) and uses the proxy configured in "Resource Management".

> This feature starts in v1.2.0. Older versions need to download this version's zip manually.


**Full Changelog**: https://github.com/kaolenmea/zzz-lost-void/compare/v1.1.2...v1.2.0
