## 更新内容

### 新增

- **新手教程**：主页最上方新增醒目的「第一次使用？」横幅，点「查看新手教程」弹出分步教程，分「开始前准备 / 设置页 / 迷失之地 / 战斗助手 / 常见问题」五个标签，按步骤讲怎么设置、怎么开始、按键是什么。第一次运行时，快速设置完成后会自动弹出一次。
- **设置项说明**：设置页、迷失之地页、战斗助手页里每个选项的标题后面多了一个「!」，鼠标放上去显示大白话解释，写清这个选项是什么、默认值、什么时候才需要改。

### 修复

- 新手教程里 HDR 的说明不准确：程序自动启动游戏时会自己关闭 HDR，只有手动打开游戏才需要先点「禁用 HDR」。

## What's Changed

### Added

- **Beginner tutorial**: a prominent "First time here?" banner at the top of the home page opens a step-by-step tutorial with five tabs (Before you start / Settings / Lost Void / Battle Assistant / FAQ). It also opens once after the quick setup on first run. The tutorial text is in Chinese only.
- **Option help tips**: every option on the Settings, Lost Void and Battle Assistant pages now has a "!" icon next to its title. Hover it to see a plain-language explanation of what the option does, its default and when you need to change it. The explanations are in Chinese only.

### Fixed

- The tutorial's HDR note was inaccurate: the app turns HDR off by itself when it launches the game; you only need to click "Disable HDR" when you start the game manually.
