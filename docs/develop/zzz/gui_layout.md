# GUI 界面结构与设置分级

本项目只有「迷失之地」和「战斗助手」两个功能，GUI 按「少入口、配置和开始在同一屏」组织。新增界面或设置项时按本文放置。

## 导航结构

入口在 `src/zzz_lv/gui/app.py` 的 `create_sub_interface`。

| 位置 | 导航项 | 界面类 | 内容 |
|---|---|---|---|
| 顶部 | 主页 | `HomeInterface` | 运行准备状态卡片 + 迷失之地 / 战斗助手两张功能卡片 + 快捷键提示，见下方「主页」 |
| 顶部 | 迷失之地 | `LostVoidInterface` | 3 个 tab：运行 / 挑战配置 / 预备编队 |
| 顶部 | 战斗助手 | `BattleAssistantInterface` | 自动战斗、闪避助手切换，配置 + 开始/停止 + 日志 |
| 顶部 | 画中画 | `PipButton` | 开关按钮，不是页面 |
| 底部 | 开发工具 | `AppDevtoolsInterface` | 只在开发者模式下显示 |
| 底部 | 资源管理 | `ResourceManagementInterface` | 模型下载、下载源、网络代理 |
| 底部 | 设置 | `AppSettingInterface` | 游戏设置 / 悬浮层 / 脚本环境 / 推送 / 自定义 |

### 主页

不用背景图，按 Fluent 设置页的卡片风格排版，从上到下：

1. 标题区：项目名 + 一句话说明，右侧 GitHub 链接。
2. 运行准备卡片：调用 `check_pre_flight`。全部就绪时只显示一行「准备就绪」；有问题时逐条列出，每条带「前往」按钮跳到对应设置页。
3. 两张功能卡片并排：
   - 迷失之地：显示挑战副本、挑战配置、刷取目标、本日/本周通关次数；「配置」跳到迷失之地页，「开始运行」先做准备检查再跳到运行页并开始，运行中改为「查看运行」。
   - 战斗助手：显示战斗配置、闪避方式、后台模式；「打开战斗助手」跳到战斗助手页。
4. 快捷键提示：开始/暂停、停止的按键。

启动时 ctx 在后台初始化，迷失之地配置要等应用注册完才能读：卡片先显示「加载中…」，`app_setting_manager.ready` 信号到达后再刷新。

主题色：不再从背景图取色。未开启「设置 → 自定义 → 自定义主题色」时用默认蓝色 `(0, 120, 215)`，开启后用保存的颜色；启动时在 `app.py` 的 `main()` 里设置。

### 迷失之地

- **运行**（`LostVoidRunInterface`）：左侧放常用配置（挑战副本、挑战配置、刷取目标、每天/每周次数、运行记录、结束后），右侧是开始/停止和日志。
  - 「结束后」沿用 `one_dragon_config.after_done`，运行线程结束后调用 `execute_after_done`，只在正常跑完时执行。
  - 没打开游戏时，`Operation` 自带的「检测游戏窗口 → 打开并进入游戏」节点会按「设置 → 游戏设置」里的游戏路径、区服、账号自动启动并登录，不需要单独开关。
- **挑战配置**（`LostVoidChallengeConfigInterface`）：编辑 `config/lost_void_challenge/*.yml`。下拉里不显示 `parameter_template.sample.yml`（它只是参数说明模板）。
- **预备编队**（`PredefinedTeamInterface`）：编辑游戏内预备编队对应的角色，可自动识别。

### 去掉的上游页面

一条龙、应用运行在本项目里都只能运行迷失之地，和迷失之地运行页重复；账户管理（多账号）只服务于一条龙的「全部账号轮流跑」。三个页面都已去掉：

- 游戏路径、区服、自动登录账号搬到「设置 → 游戏设置」顶部的「游戏」分组，读写当前实例的 `game_account_config`。
- 应用层的 `ZOneDragonApp` 和框架层的 `OneDragonRunInterface` / `StandaloneRunInterface` / `SettingInstanceInterface` 保留，CLI 和后端仍可使用。

## 设置项三档分级

每个设置项按「普通用户多久改一次」放到下面三档之一：

| 档位 | 放法 | 例子 |
|---|---|---|
| 常用 | 直接显示 | 挑战副本、战斗配置、闪避方式、后台模式、按键 |
| 高级设置 | 放进页面里的 `ExpandSettingCardGroup`，标题「高级设置」，默认折叠 | 挑战配置的商店/藏品/区域优先级；战斗助手的 GPU 运算、截图间隔、终结技一好就放；悬浮层的字体、透明度、刷新间隔 |
| 开发者模式 | 按 `ctx.env_config.developer_mode` 控制显隐 | 战斗状态面板、使用合并配置文件、战斗/闪避配置删除按钮；悬浮层的调试面板、视觉绘制、性能指标、截图补丁；脚本环境的调试模式、截图键、调试键；整个开发工具页 |

判断依据：

- 改错了会让功能跑不起来、且普通用户能理解的 → 常用。
- 普通用户能理解但一般保持默认就行的调参 → 高级设置。
- 只在调试模板、排查识别问题、开发新功能时才用的 → 开发者模式。

### 开发者模式显隐的刷新方式

- 开发者模式在「设置 → 脚本环境」里开关，或连点标题栏版本号 7 次打开。切换时主窗口 `MainAppWindowBase._apply_developer_mode_visibility` 会调用每个**顶层导航页**的 `_update_developer_visibility()`。
- 顶层导航页（如 `BattleAssistantInterface`）实现 `_update_developer_visibility()`，并在 `on_interface_shown` 里也调一次。
- tab 里的子页面（如设置下的各 tab）不会收到主窗口的调用，在自己的 `on_interface_shown` 里按当前开关刷新即可：切换开发者模式后再切到这个 tab 就会刷新。
