# 迷失之地(零号空洞·战斗肉鸽)

绝区零 1.4 版本上线的**战斗肉鸽(Roguelike)**玩法,零号空洞三大分支之一(另两个:枯萎之都 / 断层之谜)。局内逐层推进、击败首领;局外靠「调查进度等级」长线积累奖励。本文写**玩家视角机制**;画面细节见 [screens/迷失之地](../screens/迷失之地.md),自动化实现见文末「自动化说明」。

> 信息源:网络攻略(萌娘百科为主,经浏览器实读)+ 项目代码反推 + 本轮实拍。每条标置信度:**【官方】**/`【多源】**/`【单源】**/`【待确认】**;代码确认的标 **【代码】**。

## 这是什么

- **定位**:战斗肉鸽,无走格子,实时战斗 + 局内构筑(鸣徽/武备/卡牌)。`【多源】`
- **位置**:斯科特哨站(零号空洞上方枢纽)→ 零号空洞 → 迷失之地;也可「快捷手册-作战」直达。**【代码】** `LostVoidApp` 经 `TransportByCompendium('作战','零号空洞','迷失之地')` 传送。
- **解锁前置**:先解锁零号空洞(主线第二章间章「非常任务」+ 通关稳定节点第十防线)→ 完成代理人秘闻「洞中谍 上」→ 接「迷失之地」系列委托 → 完成特殊行动剧情,开启「战线肃清」。`【多源】`
- **副本分类(随版本扩充)**:
  - **战线肃清**(1.4 起):5→6 个难度,选「调查战略」+「周期增益」。
  - **特遣调查**(2.0 起):每周 UP 代理人,代理人专属武备「战术棱镜」(α/β 分支,锁定整局)。
  - **矩阵行动**(2.6 起):周期玩法，包含 3 位主战代理人和 1 位协战代理人；主题按周轮换。协战代理人有对应武备和支援技，另有探索任务与以太活性通关奖励。当前入口和具体主题以游戏内「周期」页面为准。`【单源】`
  - **【代码】** 由 `LostVoidConfig.mission_name` 选择(`战线肃清` / `特遣调查` / `矩阵行动`),app 按之分支走不同入口流程。

## 玩法目标

- **局内目标**:逐层推进,每层末击败「战斗·道中危机」(道中首领) → 经「挚交会谈」→ 击败「战斗·终结之役」(最终首领)即完成本次挑战。`【多源】` **【代码】** `LostVoidRegionType.ELITE` / `BOSS`。
- **局外长线**:通关获「阴影结晶数据」提升「调查进度等级」(原执照等级,上限以游戏内显示为准),等级奖励含菲林 / 丁尼 / 高保真母盘 / 邦布券 / 家政扫荡券。`【官方】`
- **零号业绩(=「业绩点」)**:零号空洞整体周常货币,**每周地图获取上限 900 点**,斯科特哨站 NPC「卡斯珀」处兑换(原装母带 > 邦布券 > 限购丁尼 > 代理人经验)。`【多源】` **【代码】** `run_record.eval_point_complete`、结算模板 `奖励-零号业绩`。
- **丁尼**:新艾利都基础货币(类比摩拉/信用点),通关直接掉落。`【多源】` **【代码】** 结算模板 `奖励-丁尼`。
- **周期奖励**:零号空洞每周常规奖励结算次数,**上限 45 次**(每击败一个区域首领算 1 次;完整通关 3 层 = 3 次,每周约 15 场拿满)。`【多源】`
- **菲林奖励范围**：常规副本首通与以太活性任务、周期玩法探索任务、调查进度等级、探究记录与探索收集，以及独立关卡和相关成就；不能用单项收集进度代表全部完成。`【单源】`+**【用户确认】**
  - **探究勋证**：按调查战略分别记录通用武备收集进度。特遣调查也可推进，携带通用武备首次升至三级可获得对应奖励；任务说明和进度以游戏内为准。
  - **通用武备**：较新的资料列出 10 种，包含携游、终结、机敏、异常·击破、绝境五类各两种；速刷教程说每个战略 8 个，数量以游戏内为准，不按固定数量推定刷满。
  - **图鉴和特殊条件任务**：武备、鸣徽、卡牌收集以及勘破迷踪、战地邂逅等有各自条件；没有 NEW 或战略已满不代表这些奖励完成。具体数量与要求以游戏任务为准。
  - **领取**：达成条件和领取奖励是两件事，需核对奖励页面的实际状态。
- **悬赏委托**:额外周常,进度 `xxxx/8000`(达 8000/8000 视为完成,可领全部奖励)。`【代码】** `_wait_for_lost_void_entry` → `check_bounty_commission_before` 用 OCR `'8000'` 出现次数判定(1 次=未完成、2 次=完成)。

## 经济循环(核心)

```
局内循环(每层):
  区域战斗/挑战 ──产出──> 齿轮硬币 + 鸣徽/武备/卡牌
        │                          │
        │                          └─装载/升级─> 武备强化(同流派鸣徽 2/4/6 → 2/3/4 级)
        │
        └──邦布商店──(花齿轮硬币)──> 买鸣徽/卡牌 + 刷新(50/100/200/300)
        │
        └──路径迭换──(花定位卡)──> 刷新地图样式,改路
        │
        ▼
  道中危机(ELITE)─胜─> 挚交会谈(补给/玛琳刷图)─> 终结之役(BOSS)─胜─> 结算

局外循环(每周):
  通关结算 ──> 周期奖励次数(45/周)+ 零号业绩(900/周)+ 丁尼 + 阴影结晶数据
        │
        └─阴影结晶数据─> 调查进度等级↑ ─> 等级奖励(菲林/母盘/邦布券/扫荡券)
```

**关键循环特征**:局内是「**战斗产出资源 → 资源转化为战力(鸣徽升武备 / 商店采购)→ 推进更深**」的滚雪球;局外是「**通关 → 调查进度等级 → 长线奖励**」的周积累。构筑质量(鸣徽/武备流派协同)决定能推进的深度。

## 核心机制

- **构筑(Roguelike 核心)**:鸣徽分流派,武备靠装同流派鸣徽升级;好构筑 = 同流派协同 → 战力滚雪球。**【代码】** 选择优先级由 `artifact_priority` / `artifact_priority_2` / `artifact_priority_new`(优先 NEW)/ `region_type_priority` 配置,战斗中还会按当前队伍代理人类型**动态追加优先级**(`append_agent_type_priority`)。
- **特遣调查 / 矩阵行动 的「战术棱镜」锁定**:选了某代理人/某分支后,其余本局不可再得 → 选角即定路线。`【多源】` **【代码】** `GEAR_BRANCH`、协战代理人属性会被追加为鸣徽第一优先级。
- **区域类型驱动**:每层由若干「区域类型」组成,类型决定产出(硬币/鸣徽/武备)与玩法(战斗/挑战/事件/商店)。完整区域类型表见下「子玩法」。
- **挚交会谈的多角色**:每层 Boss 战前的会谈区,可遇 NPC(阿援 / 玛琳 / 奥菲莉亚 等),功能含刷图(玛琳-定位卡)、商店、补给。`【代码】** `move_after_interact` 按 NPC 名做不同移动(避开障碍)。
- **以太活性 / 难度**:特遣调查高活性下不再提供商店与生命恢复、所有刷新次数变 1(1.6 起部分模式统一刷新为 1 次)。`【多源】`

## 子玩法(区域类型 + 交互)

- **战斗结束的标志**:区域里的怪清完后,画面上会出现指向下一处的白色圆点,下面带「23.5m」这样的距离文字;只要出现它就说明战斗结束了(2026-10-22 用户实测截图)。
- **复杂区域**(门的标签是「复杂区域」,对应地图上的混合节点)里有多个房间:打完第一个房间后要走去下一个房间(2026-10-22 用户实测)。

每层由以下区域类型构成(玩家视角作用,`【多源】`;代码区域类型见 `LostVoidRegionType`):

## 日常 / 周期

- **周期奖励结算**:每周 **45 次**(每击败一个区域首领 = 1 次)。`【多源】`
- **零号业绩**:每周地图获取上限 **900 点**。`【多源】`
- **悬赏委托**:每周 `xxxx/8000`,达 8000 可领全部。`【代码】**
- **调查进度等级**:长期累计，上限和剩余奖励以游戏内显示为准，不按周清空。`【多源】`
- **特遣调查 / 矩阵行动**:每周 UP 代理人轮换(矩阵行动每周 UP 两主战 + 一协战)。`【官方】`/`【单源】`

## 入口

大世界 → 快捷手册(作战)→ 迷失之地 → 入口画面(周期/常规)→ 选择副本、该模式提供的战略或增益及编队 → 出战 → 逐层挑战。矩阵行动包含主战与协战编队；各模式可选项不同，不能把战线肃清的准备步骤直接套用到所有模式。

**入口层(第一层)交互机制**(2026-08-20 实拍确认 + 2026-08-26 冻结入口层逐步实测,`【单源】`+**【代码】**):
- 开局站台有多个相邻 NPC:蕾(通用武备/初始武备选择)、奥菲莉亚(代理人武备;特遣调查下为战术棱镜)、神出鬼没的研究员(2.0 特遣调查,给卡牌礼物);各自头顶感叹号。入口层地图有多种布局(码头斜坡版 / 警戒区版等),NPC 与下层入口的相对位置随布局变化。
- **选完武备携带后,NPC 头顶感叹号消失,但 NPC 本体仍可重复交互**(可反悔换选)→ 再次交互会重新打开同一个武备选择画面。
- **交互判定:角色朝向 180° 扇面内,优先级 角度>距离**;朝向 = 最后一次移动方向。站在两个相邻 NPC 之间朝向不对时,按交互会命中刚选完的 NPC 而不是目标 NPC。
- **当前会被交互键命中的对象,头顶感叹号变大且下方显示「> 名字 <」标签(只有它显示)**——交互文本 OCR 读到的就是按下交互会命中谁,可作按键前的可靠信号。
- 下层入口(门)的标签是区域类型名(如「战斗·鸣徽」);**一扇门上方有多个区域图标的混合入口,标签是「复杂区域」**,看不出具体类型(2026-10-22 实测日志 + 卡住截图:门上方 鸣徽/武备/鸣徽 三个图标,标签 OCR 读到「复杂区域」,按交互后进入下层)。
- **朝目标方向迈一小步(0.1~0.3 秒)瞄准即切换**(标签跟着换);鼠标滚轮只是相机缩放,切换不了交互目标。
- 自动化若不处理会死循环:选完蕾 → 走向旁边感叹号 → 交互又命中蕾 → 重开同一画面(整套识别约 40 秒)→ 循环到 10 分钟超时。自动化处理见[迷失之地自动化](../../develop/zzz/application/lost_void/README.md#层间移动与入口交互)。

## 速刷图鉴策略（教程）

来源：B 站《绝区零迷失之地别乱刷了！这样速通图鉴！》（BV1y2Lh6KESx），原文已不在仓库里。`【单源】`

- **副本与难度**：探究勋证用战线肃清难度五及以上刷。带还没刷满的调查战略，一个战略刷满就换下一个，不要一个用到底。
- **探究勋证的推进方式**：开局选一个还没激活过的通用武备，在一局里收集同派系鸣徽把它升到 3 级，通关后该战略的勋证进度 +1。拿到 2 个同派系鸣徽升 1 级，4 个升满 3 级。
- **同派系抱团**：同派系的武备共用一套鸣徽，局内再遇到武备也优先拿同派系的；集齐 4 个同派系鸣徽后，身上所有同派系武备一起升到 3 级，运气好一局能激活 3~4 个。
- **路线**：武备格 > 限时格 > 金币格；金币用来在邦布商店买同派系鸣徽补齐。
- **卡牌图鉴**：卡牌只来自偶遇事件和代价之间。偶遇事件同时出现两张新卡时，先选一张，不离开房间，暂停 →「重新挑战本间」，回来再拿另一张；角色武备分支也能这样补。秘宝猎人战略每层休息区送一张随机卡牌。
- **武备 / 鸣徽图鉴**：刷勋证时顺带解锁。没有对应角色的武备去难度四用试用角色；异形鸣徽、战术交流鸣徽要特定角色和条件。
- **战地邂逅**：难度四以上用指定代理人完成战斗条件，没有角色就用难度四试用角色；多数打完第一层首领就能退出。**勘破迷踪**：只在难度六完成。
- **作战潜能**：先点满「金币四件套」（盗洞秘宝、铺面改装、理财思维、追加奖金），再点 30% 生命复活。
