# 使用手册

这份手册给下载了免安装包的用户。想从源码运行或参与开发，看 [开发文档](../develop/README.md)。

## 开始使用

1. 到 [Releases](https://github.com/kaolenmea/zzz-lost-void/releases) 下载最新的 `ZZZLostVoid-vX.Y.Z.zip`，**完整解压**到一个固定的文件夹（路径里尽量不要有中文和空格，不要在压缩包里直接运行）。
2. 把游戏设成 1920×1080（窗口或全屏都可以）。
3. 双击 `ZZZLostVoid.exe`，在弹出的权限窗口点「是」。游戏是管理员权限运行的，程序没有管理员权限就点不了游戏。
4. 第一次运行会先显示使用须知，然后弹出「快速设置」，选好刷取目标、计划刷取次数、预备编队，点完成。
5. 进入「迷失之地」页，点右侧「开始运行」。程序没找到游戏时，会按「设置 → 游戏设置」里填的游戏路径自动启动并进入游戏。

## 迷失之地怎么设置

| 设置 | 说明 |
| --- | --- |
| 刷取目标 | 完成悬赏委托：刷到每周 8000 积分奖励就停。刷满业绩点：刷到每周零号业绩点满。获取大部分菲林奖励：自动在战线肃清收集首通和以太活性等奖励，不能自动确认全部奖励已拿完，需要你自己在游戏里核对。 |
| 计划刷取次数 | 通关这么多次后自动停止（1~99）。下次点开始重新计数。 |
| 难度 | 只对「获取大部分菲林奖励」生效，可选难度一到难度六，默认难度五。难度六需要游戏里已解锁。 |
| 活性增幅 | 只对「获取大部分菲林奖励」生效。「不选」不碰这一栏；「指定点数」选到你设定的点数；「自动选满」尽量选满 9 点。活性越高敌人越强，自动战斗更容易失败，不熟悉就保持「不选」。 |
| 预备编队 | 出战前自动选游戏里的「编队 N」。「不选择」沿用游戏当前编队。 |
| 结束后 | 跑完后做什么，比如关闭游戏、关机。只在正常跑完时执行。 |

周期增益固定选第二个，不需要设置。

想看更多设置：「设置 → 环境」打开「显示高级设置」。

## 常见问题

**双击后没反应，或提示找不到程序文件**
确认压缩包已经完整解压，并且 `ZZZLostVoid.exe` 和 `python`、`src` 文件夹在同一个目录里。不要把 exe 单独拖到别处。

**杀毒软件报毒或拦截**
启动器 exe 没有代码签名，部分杀毒软件会误报。程序是开源的，你可以把解压目录加入白名单，或者按 [打包说明](../develop/setup/release.md) 自己打包。

**点了开始，游戏里没有反应**
- 确认程序是用管理员权限运行的。
- 确认游戏分辨率是 1920×1080。
- 游戏窗口不要最小化，也不要被别的窗口盖住。

**运行到一半停了 / 卡住了**
把程序目录下 `.log` 文件夹里最新的日志文件拿去 [提 issue](https://github.com/kaolenmea/zzz-lost-void/issues/new/choose)，并说明卡在哪个画面。

**提示缺少模型文件**
发布包已经带了模型。如果误删了 `assets/models` 里的文件，重新解压一份覆盖即可。

**怎么升级到新版本**
下载新版压缩包，解压到新的文件夹。想保留设置，把旧版 `config` 文件夹里你自己的设置（数字命名的实例文件夹、`env.yml`、`one_dragon.yml` 等）复制到新版的 `config` 里。
